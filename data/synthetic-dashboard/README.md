# Synthetic Dashboard Data

This folder contains synthetic files for dashboard prototyping.

- `kpis.json`: summary KPI cards.
- `monthly_metrics.json`: monthly basin time series (`upper`, `middle`, `lower`).
- `projects.json`: intervention portfolio with project metadata.
- `risk_matrix.json`: heatmap-ready monthly risk matrices by basin.

All values are artificial and intended only to test layout, interaction patterns, and chart styling.
